Akses instalasi

Gunakan token yang diberikan pengelola VPS. Token hanya berlaku untuk pemasangan pertama.

Database PostgreSQL

Database harus sudah dibuat dan masih kosong. Gunakan koneksi langsung, bukan pooler. Jika password berisi karakter khusus, gunakan format URL encoding.

Akun Superadmin

Minimal 12 karakter. Simpan password ini untuk masuk setelah instalasi.

Pengaturan setelah login

Nama instansi, logo, wilayah, dan gambar latar menggunakan menu Data Wilayah. Template 45 OPD, 603 keyword, dan routing OPD ikut dipasang dan bisa disesuaikan melalui admin. AI, email, dan Telegram diatur dari menu admin. Scheduler tetap nonaktif sampai diaktifkan admin.
